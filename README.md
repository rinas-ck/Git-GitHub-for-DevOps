# 🔐 Git Security Practices

Security is an important part of working with Git and GitHub.

### Never Commit

- ❌ Passwords
- ❌ API keys
- ❌ Cloud credentials
- ❌ Access tokens
- ❌ Personal Access Tokens
- ❌ Private SSH keys
- ❌ Database passwords
- ❌ Sensitive configuration files

### Good Practices

- ✅ Use `.gitignore`
- ✅ Use environment variables
- ✅ Use GitHub Secrets where appropriate
- ✅ Protect sensitive credentials
- ✅ Use SSH securely
- ✅ Rotate credentials if accidentally exposed
- ✅ Review files before pushing
- ✅ Never hard-code secrets into source code
