WHAT IS
DEVOPS?

DevOps is a culture and set of practices that bridges software development (Dev) and IT operations (Ops) to deliver software faster and more reliably.

🏗️

INFRASTRUCTURE AS CODE

Instead of manually clicking in AWS console, you write code (Terraform) that describes your infrastructure. Version controlled, repeatable, reviewable — just like app code.

🔄

CONTINUOUS INTEGRATION

Every time you push code to GitHub, an automated pipeline runs: tests, builds a Docker image, scans for security issues. No manual steps — all automatic.

🚀

CONTINUOUS DEPLOYMENT

After CI passes, your code is automatically deployed to production. Zero downtime deployments using Kubernetes rolling updates — users never see an outage.

📊

OBSERVABILITY

Know what your app is doing at all times. Prometheus collects metrics, Grafana visualizes them, and alerts wake you up before users notice something is wrong.

// 05 — Concepts

KEY
CONCEPTS

The mental models every DevOps engineer needs.

Pod

KUBERNETES POD

The smallest deployable unit in K8s. Usually 1 container. Has its own IP. Ephemeral — if it crashes, K8s creates a new one automatically. Never SSH into a pod to fix things.

IaC

INFRA AS CODE

Your infrastructure is defined in code files, stored in Git, reviewed in PRs. No manual clicking. If you need to recreate everything — just run terraform apply again.

HPA

AUTO SCALING

Horizontal Pod Autoscaler watches CPU/memory. Traffic spike hits 70% CPU? K8s automatically adds more pods. Traffic drops? It scales back down. Zero manual intervention.

SVC

K8S SERVICE

A stable endpoint for your pods. Pods come and go with new IPs — the Service always has the same address and load balances across all healthy pods automatically.

ECR

IMAGE REGISTRY

Like GitHub but for Docker images. CI builds your image, tags it with the git SHA, and pushes it. EKS pulls from ECR when deploying. Full image history maintained.

CVE

SECURITY SCANNING

Trivy scans your Docker image for known vulnerabilities before deploying. Critical CVEs fail the pipeline — you fix the base image or dependency before it reaches production.
